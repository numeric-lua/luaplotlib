# luaplotlib 4.12.0

- polar line, scatter, and bar plots (`plt.polar`, `fig:polar`,
  `fig:polar_scatter`, `fig:polar_bar`);
- circular grid, theta degree labels, radial grid circles, and automatic rmax;
- `fig:polar_config` for zero location, direction, explicit rmax, and custom
  angular/radial grids;
- degree-based theta input for every polar series method;
- polar legend, scene export, and subplot composition;
- 149 tests.
