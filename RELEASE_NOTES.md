# luaplotlib 1.3.0

Pure-Lua, matplotlib-inspired SVG/HTML plotting.

## Highlights

- `fill_between` bands;
- `step` plots with pre/post/mid semantics;
- `stem` plots with baselines and markers;
- `stackplot` areas with labels and colors;
- scene export for all four;
- 106 tests.

## Install

```sh
luarocks --lua-version=5.1 install luaplotlib
```
