# luaplotlib 0.3.0

Pure-Lua, matplotlib-inspired SVG plotting.

## Highlights

- logarithmic axes with decade ticks;
- annotations and leader arrows;
- stacked/grouped bars;
- renderer-agnostic scene export;
- 76 tests.

No runtime dependencies; LuaJIT is the primary target.

## Install

```sh
luarocks --lua-version=5.1 install luaplotlib
```
